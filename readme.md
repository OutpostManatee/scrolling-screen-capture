## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Stitch seams** | Slow down auto-scroll |
| **Missing sections** | Increase scroll delay |
| **Infinite scroll** | Set max capture height |
| **Blurry output** | Use 2x resolution |
| **Sticky header dupes** | Hide header CSS |
| **Large file size** | Export as WebP |
